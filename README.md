# Nuestra historia — Soley 🩷

Página romántica interactiva para GitHub Pages.

## Publicarla
1. Crea un repositorio en GitHub.
2. Sube **todo el contenido de esta carpeta** manteniendo la estructura.
3. Ve a **Settings → Pages**.
4. En Source selecciona **Deploy from a branch**, elige `main` y `/root`.
5. Guarda y espera a que GitHub Pages publique la página.

La canción está incluida en `assets/music/` y la experiencia está preparada para comenzar desde 0:14 y volver a ese punto al terminar.
